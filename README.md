# Keychain Maker

A static, in-browser web app that generates a three-layer keychain (text, outline,
base) and exports it as STEP or STL for multi-color 3D printing.

Part of Potts Print Shop. Styled to the Potts blueprint theme (Lemon Milk headings).

## Status

Scaffold only. The generator itself is in progress.

## Hosting

Plain static files, no build step. Serve the repo root with any static server
(for example `python3 -m http.server`) or publish it with GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root).

## Fonts

`fonts/` holds the bundled fonts: Lemon Milk (Bold, Medium) and Carter One
(SIL Open Font License).
