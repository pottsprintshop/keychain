Nerd Shite

QR code on the back

The code is just the modules, added in a color that contrasts with the base: light on a dark base, dark on a light base. Turn the keychain over like a page and it reads correctly. A Rectangle base (under Layers) leaves room for a bigger, easier-to-scan code.

Nerd Shite

Light-on-dark codes are a negative image. iPhone Camera and most current Android scanners read them, but a few older apps only read the usual dark-on-light. The plate adds a light square with a border behind the code, so it reads the usual way.
